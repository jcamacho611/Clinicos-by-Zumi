# Pricing sales cheatsheet

## Clinic buyer
"We start by understanding what the clinic is actually losing to fragmentation, manual work, missed follow-up, and disconnected systems. The operating analysis is $500. If we move forward quickly, that money is credited into the next qualifying step. Implementations start at $8,000, and ongoing Klinikos access starts at $995 per month based on scope."

## Why not cheap SaaS pricing?
"Klinikos is being sold as an operating system and implementation relationship, not another isolated scheduling or charting subscription. The price depends on what we are replacing, connecting, and operating."

## Why variable usage is separate
"We include funded allowances where appropriate, but we do not hide unlimited third-party usage inside the subscription. That keeps the base economics predictable and lets the clinic pay for the capacity it actually uses."

## Grid participant
"Basic participation can start free where you are eligible. Pro tools are optional. Klinikos earns primarily when the network helps create completed value, with the exact transaction economics depending on the resource class and applicable rules."
