# Operator pricing summary

The money stack is intentionally layered:

1. Acquire serious clinic buyer with a $500 paid analysis.
2. Convert complexity into a $1,500 blueprint when needed.
3. Close $8k-$30k+ implementation based on scope.
4. Activate $995 / $1,995 / $3,995 / custom recurring software.
5. Expand through Revenue OS, Network, Zumi, integrations, capacity, and customer-funded usage.
6. Grow Grid supply with free entry, monetize power users with Pro, and monetize successful network value with configurable transaction economics.
7. Push annual prepay selectively for cash flow while protecting implementation and pass-through margins.

The objective is not the highest sticker price. It is the highest durable contribution margin and lifetime value with a credible path into the product.
