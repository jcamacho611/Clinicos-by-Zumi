## 2. Buyer-approved reference structure

Under SCWDB Q20, the final three references may come from relevant comparable engagements performed by:

- key personnel;
- affiliated organizations;
- predecessor entities;

when they are being relied upon to demonstrate qualifications/experience of the proposed team.

Every final reference should make these four facts unmistakable:

1. **ACTUAL PERFORMER** — who performed the work;
2. **RELATIONSHIP TO KLINIKOS** — key person / affiliate / predecessor / team member / subcontractor;
3. **PROPOSED KEY PERSON ROLE** — what the person did in the referenced engagement;
4. **COMPARABLE SERVICES** — what was actually delivered and why it maps to this RFP.

## 3. Reference scoring test

Do not use a reference merely because the person likes, knows, taught, employed, or worked with a proposed team member.

Score each candidate reference 0-2 on each dimension:

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Live instruction/facilitation | None | Some enablement/presentation | Repeated live instruction/workshops |
| AI/digital-skills relevance | None | General digital/IT | Direct AI/digital-skills training |
| Workforce/career-readiness relevance | None | General professional development | Direct workforce/job-seeker/employer training |
| Occupational/pathway relevance | None | Adjacent | Manufacturing/construction/logistics/healthcare/business ops directly |
| Measurable delivery scope | Unclear | Bounded project | Cohort/participants/hours/outcomes documented |
| Dated source evidence | None | Partial | Strong contemporaneous records |
| Verifier quality | Cannot verify | Can verify some facts | Direct client/program owner can verify work |
| Permission | No | Pending | Affirmative |

A final Appendix C reference should normally score at least **11/16**, with no zero for dated source evidence, verifier quality, or permission.

This is an internal quality threshold, not an SCWDB-issued scoring rule.
