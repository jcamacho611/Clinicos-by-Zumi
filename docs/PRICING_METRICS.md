# Commercial metrics

North-star commercial metrics:
- implementation cash collected
- net new MRR / ARR
- contribution margin
- expansion revenue
- Grid gross transaction value and net platform revenue

Funnel:
visit -> qualification -> analysis paid -> blueprint -> implementation -> recurring activation -> 90-day retention -> expansion.

Track price realization, discounting, sales cycle, implementation hours, support burden, vendor/API cost, payment cost, refund/dispute cost, usage-pack margin, add-on attach, annual prepay, Grid liquidity, match-to-transaction conversion, repeat transaction rate, and cohort retention.
