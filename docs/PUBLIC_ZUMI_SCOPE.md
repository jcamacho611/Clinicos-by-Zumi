# Public Zumi scope

In scope: public Klinikos explanation, public navigation, general clinic-operations discussion, Grid/EDU/product discovery, and identifying a public-safe next step.

Out of scope: tenant/private data, patient records, authenticated memory, clinic mutations, payments, credentials, regulated eligibility, clinical decisions, diagnosis/prescribing, private files, and unrestricted external tools.

The public surface is an acquisition and navigation experience. It does not become an alternate anonymous clinic session merely because a model can converse naturally.
