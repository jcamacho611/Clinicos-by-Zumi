## Every council opens with truth and expiry

```
/CURRENT_TRUTH             what is verifiably true right now
/VERIFIED_AT               date and method
/SOURCE                    where the evidence came from
/EXPIRY_OR_REVERIFY_TRIGGER what makes this stale
```

## Every council closes with dissent

```
/DISSENT   the strongest argument against the recommendation, stated honestly
```
