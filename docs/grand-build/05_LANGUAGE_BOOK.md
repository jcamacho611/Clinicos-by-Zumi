plain words work.

## The permanent question

> **What needs to happen?**

Not "Dashboard." Not "Welcome back."

> ~~"you'll be the first person it reaches."~~

## Grid results require evidence

Only render a count the server actually proved:

> **6 professionals meet every requirement.**

If it cannot be proven:

> **No currently eligible professionals match every requirement.**

Never fabricate liquidity. An empty network stated honestly still converts; a fabricated one
destroys trust permanently.

## Outcome language, never system language

**Living Home — correct:**

> **Three things need you.**
> **Care** — 2 results haven't been reviewed
> **Money** — $8,420 isn't billing-ready
> **People** — Friday has one uncovered shift

**Never:** "Workflow orchestrator has unresolved state transitions."

Each figure carries a truth chip and an evidence row, or it does not render.

## Disabled controls always say why

> Send for review
> *Only the treating provider can sign this note.*

A disabled control with no reason is a defect.

## Intent is never reality

Where a capability is intended but not verified live, say both, separately:

> **Where it actually is:** Partly built
> **What we intend:** Now

verified live — see `06`. The copy must survive that fact being true.
