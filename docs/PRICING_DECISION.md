# Pricing decision

Decision date: 2026-08-12
Status: V1 proposed implementation, pending CI/build/deployment verification and commercial/legal review where required.

Chosen model:
- $500 Clinic Operating Analysis.
- $1,500 Implementation Blueprint.
- Implementation from $8,000.
- Core $995/mo.
- Growth $1,995/mo.
- Scale $3,995/mo.
- Enterprise custom.
- Optional annual commitment at ~15% savings on recurring software, not implementation/pass-through costs by default.
- Grid basic entry free where eligible.
- Grid Pro: Professional $39/mo; Facility $99/mo; Seller $49/mo.
- Grid completed-transaction launch midpoint 10% where appropriate, but server-owned resource-class configuration and legal review are authoritative.
- Variable external usage customer-funded before execution.

Reasoning: maximize lifetime value through implementation + recurring + expansion + usage + network economics while preserving low-friction Grid liquidity and preventing Klinikos from subsidizing unbounded vendor spend.
