# Black Label V2 implementation notes

This is a conversion guide, not a second frontend architecture.

## Preserve

- current Next.js route and auth structure;
- production brand components and rose atmosphere;
- current server-owned domain truth and DTO boundaries;
- existing Zumi, Grid, EDU, finance, audit and identity substrates;
- current first-visit Living Home pixel lock.

## Reconcile next

1. PR #240 Marble / Obsidian theme work into current `main` rather than creating another theme provider.
2. Shared authenticated shell/navigation and role/context emphasis.
3. Reusable Object Stage / inspector presentation primitives.
4. Authenticated Living Home recomposition around intent.
5. Current Visit / Clinical Change Black Label convergence.
6. Front Desk, Billing, Grid, EDU and Patient deep-route convergence.

## Never infer from the prototype

- real patient state;
- payment or settlement;
- claim acceptance;
- provider/credential verification;
- Grid eligibility or ranking authority;
- external integration readiness;
- attendance, competency or certification;
- any PHI-production readiness claim.

The prototype specifies how governed truth should feel when presented. It does not manufacture the truth itself.
