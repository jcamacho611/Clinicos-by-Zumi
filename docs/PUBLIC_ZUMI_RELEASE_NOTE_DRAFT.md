# Public Zumi release note draft

Public Living Home now has two separate safety layers:

1. a deterministic public navigator that remains available without a model provider; and
2. a bounded anonymous intelligence route that can improve ordinary conversation without borrowing authenticated clinic authority.

The public route intentionally has no tenant/session access and no web, file, code, payment, clinical, credential, or mutating tools. Identifier-bearing, private-record, and individualized clinical-advice turns fail closed before provider inference. Provider/model/cost details remain server-side.

The responsive composer correction that prevents half-window text collapse landed separately before this slice.

Do not publish this release note until exact-head executable verification and deployed production proof are complete.
