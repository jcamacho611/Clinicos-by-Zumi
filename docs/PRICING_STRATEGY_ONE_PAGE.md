# Klinikos pricing V1 — one page

Clinic funnel: $500 analysis -> $1,500 blueprint if needed -> $8k+ implementation -> $995/$1,995/$3,995/custom monthly -> add-ons + funded usage + expansion.

Grid funnel: free eligible basic participation -> optional $39 Professional / $99 Facility / $49 Seller Pro -> configurable completed-value transaction economics around a 10% launch midpoint where appropriate.

Why: monetize high-touch expertise upfront, create meaningful recurring revenue, preserve expansion revenue, grow Grid liquidity, and never subsidize unlimited external vendor usage.

What protects margin: customer-funded reservation-before-spend, annual prepay option, implementation minimums, add-ons, connector/pass-through pricing, enterprise custom scope, server-owned transaction policies.

What protects trust: no fake connected integrations, no fake automated payouts, no broad live free trial, no payment bypass of governance, no universal regulated percentage fee without review.
