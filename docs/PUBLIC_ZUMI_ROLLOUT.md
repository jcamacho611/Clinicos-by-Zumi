# Public Zumi rollout

1. Merge only after exact-head code verification can execute or equivalent trusted local verification is recorded.
2. Deploy through the normal `main` production path.
3. Confirm `/api/health` reports the deployed merge SHA.
4. Exercise the public conversation at desktop, half-window, tablet, and mobile widths.
5. Confirm the configured provider actually runs for a controlled non-sensitive free-form product question.
6. Confirm private-record, identifier-bearing, and clinical-advice requests do not reach provider inference.
7. Confirm provider failure returns useful deterministic guidance.
8. Watch public provider cost/token telemetry and rate-limit pressure before increasing public traffic.
9. Add a distributed/edge limiter before scaling anonymous inference across multiple application instances.
